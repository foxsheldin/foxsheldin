I build web applications from interface to backend: designing APIs and data models, integrating external systems, and bringing products closer to release. I also work on practical AI features, including LLM orchestration and tool use.

## 🧠 My Approach

I treat AI as an engineering tool, not a replacement for engineering judgment.

I use AI-assisted workflows for planning, implementation, testing, and code review, while validating critical logic through automated checks, documentation, and manual verification.

I value **clarity, maintainability, reliability, and pragmatic architecture**.

## How I work

I care about clear architecture, maintainable code, and systems that handle failure well. I use AI assistants throughout development, with tests, static analysis, source verification, and manual review of critical logic.
